Rediseño y Optimización Web Institucional — INSM (v2.0)

Este repositorio contiene la versión optimizada del sitio web institucional para el **Instituto Nuestra Señora de la Merced** (Año 2026). El proyecto fue restructurado para mejorar el rendimiento, la accesibilidad, el SEO y permitir un despliegue continuo en la nube.

El sitio está estructurado para servirse directamente desde la carpeta `/docs`:

```text
pagina_web_2026/
├── docs/
│   ├── index.html              # Portada / Inicio
│   ├── home.html               # Página principal con optimizaciones SEO
│   ├── inicial.html            # Nivel Inicial
│   ├── primaria.html           # Nivel Primario
│   ├── secundaria.html         # Nivel Secundario
│   ├── terciario.html          # Nivel Terciario
│   ├── proyectos.html          # Proyectos Institucionales
│   ├── contacto.html           # Formulario y mapa de contacto
│   ├── login.html              # Portal de acceso institucional
│   ├── sitemap.xml             # Mapa del sitio para indexación
│   ├── robots.txt              # Reglas para motores de búsqueda
│   └── manifest.webmanifest    # Configuración PWA
├── vercel.json                 # Configuración de enrutamiento y cabeceras
└── README.md                   # Documentación técnica
